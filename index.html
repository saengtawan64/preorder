วิธีสร้าง Firebase Project ฟรี 3 ขั้นตอน

  1. ไปที่เว็บ console.firebase.google.com แล้วเข้าสู่ระบบด้วย Google Account
  2. กด Add Project (สร้างโปรเจกต์) ตั้งชื่อแล้วกด Continue จนสร้างเสร็จ
  3. ที่หน้า Dashboard เลือกไอคอนเว็บ Web (</>) ตั้งชื่อแอป แล้วคัดลอกส่วน const firebaseConfig = { ... }; มาวางในช่องด้านบนแล้วกดบันทึก
